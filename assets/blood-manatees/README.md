# Blood Manatees assets

Place future files in `images/`, `audio/`, `music/`, or `storyboards/`. Reference them from a scene's front matter with a site-root path, for example:

```yaml
image: /assets/blood-manatees/images/<filename>
image_alt: Description of the image
audio: /assets/blood-manatees/audio/<filename>
```

Missing optional assets are safe: omit their fields and the scene remains text-only.
